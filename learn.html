두 수의 합 구하기

정수 a와 b가 주어질 때, a와 b의 합을 반환하는 함수 solution을 완성하세요.

제한 사항

  • -1,000 ≤ a, b ≤ 1,000
  • a와 b는 정수입니다.

입출력 예

a3
b5
return8
a-2
b7
return5

기본 개념 · 함수와 반환값

함수는 입력(매개변수)을 받아 결과(반환값)를 돌려주는 코드 묶음이에요. return으로 값을 돌려주면, 함수를 부른 곳에서 그 값을 사용할 수 있어요.

def add(x, y):
    return x + y

제출 목록

제출결과시간

아직 제출한 기록이 없어요.

해설

두 수를 더한 값을 return하면 돼요. 음수가 섞여도 a + b 그대로 계산됩니다.

def solution(a, b):
    return a + b
